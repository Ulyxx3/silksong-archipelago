# Silksong Assembly Dependencies

This folder is used to resolve Silksong Unity game assemblies for building the `SilksongArchipelago` client mod.

To build the project locally, copy the following DLLs from your Hollow Knight: Silksong game installation folder (`Silksong_Data/Managed/`) into this directory:

- `Assembly-CSharp.dll`
- `UnityEngine.dll`
- `UnityEngine.CoreModule.dll`

> **Note**: Game assemblies are proprietary and copyrighted by Team Cherry and Unity Technologies. They are excluded from version control via `.gitignore` and must never be committed to the repository.
